# Execução correta

Todos os arquivos do jogo precisam permanecer na mesma pasta:

- `index.html`
- `style.css`
- `deck-builder.css`
- `cards.js`
- `game.js`
- `dev-panel.js`
- `deck-builder.js`

Não abra o arquivo pela página `github.com/.../blob/...`. Baixe o repositório ou use um servidor local.

## Servidor local

Na pasta raiz do projeto:

```bash
python -m http.server 8000
```

Depois acesse `http://localhost:8000`.
